# Сайт школы № 29 — видение

> Презентация проекта: проблема, решение, ценность. Заполнить разделы — это ответ на вопрос «почему мы это делаем».

## Проблема

- Текущий сайт школы на конструкторе Nubex — «тихий ужас»: меню 19+6 пунктов с дублями, устаревший дизайн.
- Родители и ученики с трудом находят нужную информацию: школа не на «Госвебе», структура запутанная.
- Государство предъявляет к сайтам школ жёсткие требования (ПП РФ № 1802, Приказ Рособрнадзора № 1493, ПП РФ № 102 о цифровой доступности), которым текущий сайт не соответствует.
- Сайт должен быть доступен людям с ограниченными возможностями: клавиатура, скринридеры, масштабирование 200%, контраст 4,5:1.

## Решение

1. Новый сайт на Astro + Decap CMS: быстрый статический сайт, современный и доступный.
2. Дизайн создаётся через OpenDesign — отдельный инструмент, не руками.
3. Структура строится по гос. требованиям: «Сведения об образовательной организации» с 14 подразделами, «Политика обработки ПД», форма «Обращения граждан»; контент переносится с текущего сайта.
4. Наполнять сайт сможет секретарь/учитель через веб-редактор Decap CMS — без знания кода.

## Как это выглядит для пользователя

```
Родитель открывает сайт → быстро находит «Сведения об образовательной организации» и нужный документ → видит актуальные новости, разделы ГИА, приёма в 1 класс, безопасности.
Секретарь входит в Decap CMS → редактирует страницу в веб-интерфейсе → сохраняет; изменения уходят в git.
```

## Почему это важно

- Школьный сайт — официальный канал информации для родителей, учеников и проверяющих органов; несоответствие требованиям — реальная проблема школ.
- Проект учебно-портфельный, но делается по-настоящему: соответствие гос. требованиям и современным стандартам качества — критерий успеха.
- Портфолио владельца получает реальный, серьёзно выполненный проект.

## Как измеряем успех

- Соответствие гос. требованиям: есть «Сведения об образовательной организации» с 14 подразделами, «Политика обработки ПД», форма «Обращения граждан».
- Доступность: клавиатура, скринридеры, масштабирование 200%, контраст 4,5:1.
- Скорость: быстрая загрузка (статический сайт).
- Наполнение: секретарь/учитель может сам редактировать страницы без технических знаний.
