# План: Сайт школы № 29

> План достижения цели проекта. Цель (первая полезная версия) и запреты — см. docs/context.md и docs/anti-features.md.

## 1. Продукт / цель

Современный, быстрый, доступный сайт школы № 29 им. Сепсяковой Т.Ф. (Петрозаводск), соответствующий гос. требованиям к сайтам школ, удобный для родителей и учеников, простой в наполнении для секретаря/учителя. Учебно-портфельный проект: в production не запускается, но делается как реальный.

## 3. Риски

- Потеря интереса (портфельный проект): работаем поэтапно, маленькими шагами, с короткими циклами и проверяемыми результатами.
- Перфекционизм и размывание фокуса: держимся плана, первая полезная версия — узкий путь ценности.
- Устаревание гос. требований (примеры: № 582 → № 1802, отмена версии для слабовидящих → ПП РФ № 102): перед публикацией проверять актуальность требований.
- Сложный редактор для нетехнического секретаря: Decap CMS настраиваем под простой сценарий наполнения.
