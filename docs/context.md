# Сайт школы № 29 — контекст проекта (для ИИ-советников)

## Что за проект

- Новый сайт МБОУ Петрозаводского городского округа «Средняя общеобразовательная школа № 29 им. Сепсяковой Т.Ф.» (Петрозаводск, Карелия).
- Учебно-портфельный проект: «по приколу, но полностью реальный и серьёзный». В production не запускается (решение владельца), но делается по всем современным требованиям, как будто запустится.
- Текущий сайт — https://sch29.nubex.ru/main/ на конструкторе Nubex: «тихий ужас» (меню 19+6 пунктов с дублями, устаревший дизайн). Контент разделов переносим на новый сайт.
- Школа не на «Госвебе» (проверено: 404).

## Ключевые решения (не предлагать альтернативы, не менять)

1. **Стек: Astro + Decap CMS.** Причина: статический генератор — современно, быстро, доступно; Decap CMS — git-based веб-редактор, чтобы контент мог наполнять нетехнический человек.
2. **Домен пока не нужен.** Причина: запуска в production не будет.
3. **Запуск не планируется.** Причина: проект портфельный/учебный.
4. **Дизайн создаётся через OpenDesign**, не руками.
5. **Контент будет наполнять секретарь/учитель** (нетехнический человек) — если проект когда-нибудь запустится.
6. **Работа строго поэтапно, маленькими шагами.**

## Как устроен проект

- **Astro (SSG):** статические страницы, компонентный подход.
- **Decap CMS:** веб-редактор контента; изменения сохраняются в git.
- **Контент:** Markdown-файлы в репозитории.
- **Дизайн-система:** из OpenDesign.
- Подробности — docs/architecture.md.

## Статус

- Все этапы 1–8 завершены; идёт этап 9 «Лечение сайта» (подэтапы 9.1 и 9.2 завершены, 9.3 в работе). Актуальное состояние — docs/HANDOFF.md; журнал ошибок — docs/errors.md.

## Цель / успех (первая полезная версия)

1. Современный, быстрый, доступный сайт школы, проходящий государственные проверки.
2. Удобный для родителей и учеников: нужная информация находится быстро.
3. Простой в наполнении для секретаря/учителя — без знания кода.
