# Инструменты и материалы — проект Сайт школы № 29

> Утверждённый набор инструментов и материалов. Краткое описание продукта — `docs/vision.md`, полный план — `docs/plan.md`.

---

## 1. Инструменты и материалы

| Часть | Решение | Примечание |
|---|---|---|
| Генератор сайта | Astro, актуальная стабильная версия | SSG: быстро, статично, доступно |
| Редактор контента | Decap CMS | git-based веб-редактор; наполнять сможет секретарь/учитель без знания кода |
| Формат контента | Markdown | простой для людей и для git |
| Система контроля версий | git | история, ветки, коммиты |
| Дизайн | OpenDesign | дизайн создаётся в OpenDesign, не руками |
| Хостинг | GitHub Pages (публикация портфолио) | при реальном запуске — только российский (п. 5 ст. 13 149-ФЗ) |

## 2. Жёсткие ограничения (приняты ранее)

1. Стек: Astro + Decap CMS (решение от 31.08.2026).
2. Дизайн — только через OpenDesign.
3. Запуск в production не планируется; сайт публикуется как портфолио на GitHub Pages; домен не нужен.
4. Контент наполняет нетехнический человек (секретарь/учитель) — интерфейсы и сценарии должны быть простыми.
5. При запуске — только российский хостинг.

## 3. Решения на этапе разработки (не стек)

- Точная версия Astro — актуальная стабильная на момент установки (не фиксируем заранее).
- Структура папок, список компонентов и настройка Decap CMS — по ходу разработки (этапы 4–5), с учётом утверждённой информационной архитектуры.
