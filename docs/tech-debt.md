Приоритет: high / medium / low.

## Правила

- Запись делает тот, кто принял решение отложить (или ИИ по указанию владельца).
- Пункт закрывается только реальным исправлением (с пометкой даты), не «забыванием».
- Приоритет выставляет владелец проекта.
