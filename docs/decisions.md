# Решения — хронологический журнал

> Короткий журнал ключевых решений: дата, что решили, причина. Записи не переписываются — новые решения добавляются новыми записями. Формальные архитектурные решения — отдельно, в docs/adr/ (формат — docs/adr/ADR-000-template.md).

## Правила

- Запись: `## ГГГГ-ММ-ДД` + пункты `- **Решение.** Причина: ...`
- Новые записи добавляются сверху.
- Уже написанные записи не редактируются — при изменении решения пишется новая запись.
- Решения, меняющие инварианты или устройство проекта, оформляются как ADR в docs/adr/.
