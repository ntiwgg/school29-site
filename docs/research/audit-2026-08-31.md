### Проблемные аудиты (score < 0.9)

**a11y-нарушения (влияют на балл доступности):**

2. **label-content-name-mismatch (WCAG 2.5.3)** — на всех 4 страницах (не снижает балл в LH 13, но это нарушение):
   - ссылки шапки `a[href="tel:..."]` с `aria-label="Позвонить в школу"` и видимым текстом `+7 (8142) 78-00-29`; `a[href="mailto:..."]` с `aria-label="Написать письмо"` и текстом `school29@petrozavodsk-edu.ru`. Доступное имя не содержит видимый текст.

**Информационные (не влияют на баллы, но полезно):**

3. **cache-insight «Use efficient cache lifetimes»** — все статические ассеты GitHub Pages отдаёт с `cache-control: max-age=600` (10 минут). Для хэшированных файлов (шрифты `_astro/*.woff2`, `Layout.*.css`) кэш можно увеличить; wastedBytes ~11 КБ на файл шрифта.
4. **render-blocking-insight** — 2 CSS-файла блокируют рендер: `Layout.CSmAMcqs.css` + `styles.css` (~150 ms wastedMs). Объединение или инлайн критического CSS сэкономит ~150 ms на главной/contacts.
5. **network-dependency-tree-insight** — preconnect-кандидаты не найдены (один origin — не критично).

## 2. Валидность HTML

Проверено 6 страниц (`/`, `/sveden/`, `/contacts/`, статья, `/o-shkole/`, `/news/`) двумя инструментами.

### Структурных ошибок НЕТ

- Нет незакрытых тегов, ошибок вложенности, отсутствующих `alt`.
- Все `<img>` (8 шт. на главной) имеют `alt` (декоративные — пустой `alt=""`).

### W3C Nu Validator — единственная реальная ошибка

| Страница | Ошибка |
|---|---|
| `/sveden/`, `/contacts/`, статья | `h3` следует за `h1` — пропущен 1 уровень заголовка |
| Главная | `aria-label` на `<div class="stars">` без `role` (обязателен `role="img"`) |
| Главная (info) | 2 секции без заголовков (строки 199, 380) |
| `/o-shkole/` | ошибок нет |

### html-validate — только косметические правила (не структурные)

- **tel-non-breaking** (все страницы): пробелы и дефисы в телефонных номерах без `&nbsp;`/`&#8209;` — риск переноса номера на новую строку.
- **no-trailing-whitespace** (все страницы): хвостовые пробелы в сгенерированном HTML.
- **no-inline-style** (главная, contacts, o-shkole): инлайновые `style="opacity:.35"` (звёзды рейтинга) и др.
- **aria-label-misuse** (главная): `aria-label` на `div` (см. выше).
- **long-title** (статья): `<title>` статьи 85 символов (рекомендация ≤ 70).
