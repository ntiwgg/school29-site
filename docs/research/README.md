# Исследования

Сюда класть исследования, образцы, разборы, заметки по темам проекта.

Формат: `<тема>.md` — например, `competitors.md`, `formats.md`, `materials.md`.

## Правила

- Каждый файл — одна тема.
- В начале файла: дата и вопрос, на который искали ответ.
- В конце: выводы и ссылки на решения (docs/decisions.md, docs/adr/).
- Исследование — материал для решений, а не само решение.
