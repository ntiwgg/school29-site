# Сайт школы № 29

Это репозиторий-шаблон: документация и правила работы с ИИ-ассистентом для любого проекта (рабочего, учебного, творческого, непрограммного).

## Структура репозитория

- `AGENTS.md` — правила работы ИИ в проекте: документация, запреты, конвенции, порядок чтения.
- `.ai/context.md` — короткий контекст для ИИ-советников.
- `docs/` — вся документация проекта:
  - `HANDOFF.md` — «душа» проекта: состояние, решения, что дальше;
  - `context.md` — контекст и ключевые решения;
  - `vision.md` — видение и цель;
  - `plan.md` — план и этапы;
  - `roadmap.md` — дорожная карта;
  - `invariants.md` — неизменяемые принципы;
  - `decisions.md` — журнал решений;
  - `adr/` — формальные записи решений;
  - `anti-features.md` — что не делаем до цели;
  - `architecture.md` — как устроен проект;
  - `stack.md` — инструменты и материалы;
  - `requirements.md` — требования;
  - `tech-debt.md` — долги проекта;
  - `graveyard.md` — похороненные идеи;
  - `brand.md` — бренд;
  - `research/` — исследования.

## Как начать

1. Заполнить `docs/HANDOFF.md` — состояние, решения, кто мы.
2. Заполнить `docs/context.md` — контекст и ключевые решения.
3. Заполнить `docs/vision.md` — видение и цель.
4. `AGENTS.md` уже настроен под общий процесс — дополнить при необходимости.

## Работа с ИИ

ИИ-ассистент читает `AGENTS.md` и файлы `docs/` в порядке из AGENTS.md: HANDOFF → context → invariants → architecture → plan. Правила для ИИ — в AGENTS.md; решения фиксируются в `docs/decisions.md` и `docs/adr/`.
